UN REGISTRO DEL PROCESO

De horas a segundos.

  1. Abrí la página Edit de DaVinci y acomodá las pistas.
  2. En Elegir ventana, compartí la ventana de DaVinci. Dibujá el recorte alrededor de la timeline.
  3. Presioná Grabar mi edición y volvé a editar. Mantené el navegador abierto y el equipo despierto.
  4. Al terminar, volvé, finalizá la sesión y exportá el MP4.

Chrome o Edge de escritorio recomendados. En macOS puede ser necesario habilitar grabación de pantalla para el navegador en Ajustes del Sistema.

Se guardan capturas del área visible que elegiste. No se lee ni modifica el proyecto y no se recupera historial anterior. Si cambia el encuadre, creá una sesión nueva.

Las sesiones se conservan en la carpeta local .timelinelapse. Podés descargar tus capturas con “Guardar capturas”.
